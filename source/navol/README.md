# NavOL Isaac Lab extension

This directory contains the installable `navol` Python package and its Isaac
Lab extension metadata. Install it from the NavOL repository root with:

```bash
python -m pip install -e source/navol
```

The complete installation, model/data layout, training, and evaluation guide
is in the repository root `README.md`. Import `navol.tasks` inside an active
Isaac Lab environment to register the NavOL Gym tasks.
